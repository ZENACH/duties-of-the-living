            Plan B — STM

            When the shuttle isn't running (early mornings, evenings after the last bus, weekends), STM connects the campuses:

            • 105 Sherbrooke bus — from Vendôme metro to Loyola
            • 162 Westminster bus — from Villa-Maria metro to Loyola

            For live departures right now, check stm.info. Shuttle source: Concordia's official shuttle page.

            STM live times

            Live STM predictions come from STM's official GTFS-Realtime feed. It needs two things: your own free STM developer key, and a small relay so the key never sits exposed in app code. Get the key (free, about a business day) and paste it here — DTL saves it on this device only and is ready to use it the moment the relay is switched on.

            1. Register at portail.developpeurs.stm.info and create an API key for the GTFS-Realtime feed.
            2. Paste the key below and tap Save.
            3. When the relay goes live, this card switches to real arrivals automatically.
